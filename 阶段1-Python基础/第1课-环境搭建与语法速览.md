## 二、C++ → Python 语法对照表（核心差异）

| C++ | Python | 说明 |
|---|---|---|
| `{}` 代码块 + `;` 结尾 | **缩进** 就是代码块 | 4 空格统一缩进，没有大括号和分号 |
| 强类型：`int x = 1;` | 动态类型：`x = 1` | 类型运行时推断，可重新赋值 |
| `for (int i=0; i<n; i++)` | `for i in range(n):` | 遍历风格完全不同 |
| `std::vector<int> v` | `v = [1, 2, 3]` | 列表，可混类型 |
| `std::map<K,V>` | `d = {"k": "v"}` | 字典，键值对 |
| 指针/引用 | 一切皆对象引用 | 没有指针，不用管内存释放（有 GC） |
| `cout << x` | `print(x)` | 输出；`f"{x}"` 叫 f-string 格式化 |
| 编译型 | 解释型 | 写完直接跑，不用编译；也有类型标注（可选） |

## 三、第一个程序（体验）

```python
# hello.py —— 你的第一个 Python 程序
name = input("你的名字：")          # 输入，类比 cin
print(f"你好 {name}，欢迎开始 AI 学习之旅！")

# 列表 + 循环 + 推导式（C++ 里要写好几行）
scores = [85, 92, 78, 96]
passed = [s for s in scores if s >= 60]   # 列表推导式
print("及格分数:", passed)
```

## 五、常见坑（提前避雷）

- 缩进混用 Tab 和空格 → 报 `IndentationError`（规范：全部用 4 空格）
- 忘记冒号 `:` → 报语法错误
- `print` 里字符串拼接用 `+` 遇到数字会报错 → 用 f-string
