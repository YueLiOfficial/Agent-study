## 一、继承：class Motor(Device)

```python
class Motor(Device):              # 继承 Device（类比 C++ 的 : public Device）
    def __init__(self, name, power_kw):
        super().__init__(name)    # 调父类构造（类比初始化列表调基类构造）
        self.power_kw = power_kw  # 子类自己的属性

    def start(self):              # 方法重写——不用 virtual，天然多态
        super().start()           # 复用父类逻辑（类比 Device::start()）
        print(f"  → {self.name} 功率 {self.power_kw}kW 已就绪")

m = Motor("主轴电机", 15)
m.start()                          # 调用的是重写后的 start
print(isinstance(m, Device))       # True（类比 dynamic_cast 判断）
```

| C++ | Python |
|---|---|
| `class Motor : public Device` | `class Motor(Device):` |
| `Device(...)` 基类构造调用 | `super().__init__(...)` |
| `virtual` 重写 | 直接重定义同名方法（天然多态） |
| `dynamic_cast` | `isinstance(obj, Device)` |

要点：重写后想复用父类逻辑，用 `super().方法名()`——别把父类代码复制一遍。

## 二、私有权限：Python 没有真 private

- `_x`（单下划线）：**约定**"别从外部动我"（类似 protected 的自觉版）
- `__x`（双下划线）：name mangling，变成 `_ClassName__x`，隐藏但可访问
- **实话实说**：C++ 的 private 是编译器强制；Python 是君子协定——靠命名约定 + 自觉

```python
class Device:
    def __init__(self, name):
        self._name = name     # 约定：内部属性
        self.__secret = 1     # 双下划线：会被改名为 _Device__secret
```

## 三、类属性 vs 实例属性

| 类型 | 定义位置 | 类比 | 生命周期 |
|---|---|---|---|
| 实例属性 | `__init__` 里 `self.x` | 普通成员变量 | 每对象一份 |
| 类属性 | 类体里直接写 `total = 0` | **static 成员变量** | 全类共享一份 |

```python
class Device:
    total = 0                    # 类属性（类比 static int total）

    def __init__(self, name):
        self.name = name         # 实例属性（每个对象一份）
        Device.total += 1        # 访问类属性用 类名.属性
```

## 四、@classmethod 与 @staticmethod

| 装饰器 | 第一参数 | C++ 类比 | 典型用途 |
|---|---|---|---|
| `@classmethod` | `cls`（类本身） | static 成员函数（能访问类属性） | **工厂方法**：用字典/JSON 造对象 |
| `@staticmethod` | 无 self/cls | 命名空间里的自由函数 | 工具函数：校验、格式化 |

```python
class Device:
    @classmethod
    def create_from_dict(cls, data):
        """工厂方法：cls 是类本身；子类调用时 cls 自动是子类"""
        return cls(data["name"], data.get("status", "待机"))

    @staticmethod
    def is_valid_name(name):
        """工具方法：不依赖实例"""
        return bool(name) and len(name) <= 20
```

## 五、@property（C++ getter/setter 的优雅版）

```python
class Device:
    def __init__(self, name):
        self._name = name
        self._run_hours = 0

    @property
    def run_hours(self):          # getter：d.run_hours 读取
        return self._run_hours

    @run_hours.setter
    def run_hours(self, value):   # setter：d.run_hours = 5 时自动校验
        if value < 0:
            raise ValueError("运行时长不能为负")
        self._run_hours = value
```

**用法对调用方无感**：`d.run_hours` 读、`d.run_hours = 3` 写，跟普通属性一样，但内部可以加校验/计算。C++ 里 getX/setX 两个函数，Python 合并成一个属性——这就是装饰器的力量（预告：第 8 课讲装饰器原理）。

## 六、综合案例：设备管理系统

```python
class Device:
    total = 0                     # 类属性：设备总数

    def __init__(self, name, status="待机"):
        self.name = name
        self.status = status
        self._run_hours = 0
        Device.total += 1

    @property
    def run_hours(self):
        return self._run_hours

    @run_hours.setter
    def run_hours(self, v):
        if v < 0:
            raise ValueError("运行时长不能为负")
        self._run_hours = v

    def start(self):
        if self.status == "运行中":
            print(f"{self.name} 已在运行")
            return
        self.status = "运行中"
        print(f"{self.name} 启动")

    def stop(self):
        self.status = "待机"
        print(f"{self.name} 停止")

    def __str__(self):
        return f"设备[{self.name}] 状态={self.status} 运行{self.run_hours}小时"

    @classmethod
    def create_from_dict(cls, data):           # 工厂
        return cls(data["name"], data.get("status", "待机"))

    @staticmethod
    def is_valid_name(name):                   # 工具
        return bool(name) and len(name) <= 20


class Motor(Device):
    def __init__(self, name, power_kw):
        super().__init__(name)
        self.power_kw = power_kw

    def start(self):
        super().start()
        print(f"  → {self.name} 功率 {self.power_kw}kW 已就绪")


class Pump(Device):
    def __init__(self, name, flow_rate):
        super().__init__(name)
        self.flow_rate = flow_rate


# ===== 使用：设备列表管理 =====
devices = []
devices.append(Motor("主轴电机", 15))
devices.append(Pump("冷却水泵", 30))
devices.append(Device.create_from_dict({"name": "空压机", "status": "故障"}))  # 工厂

for d in devices:
    d.start()                    # Motor 输出重写版，Pump/空压机输出父类版 → 多态
    print(d)

print("设备总数:", Device.total)  # 3
print("名字合法?", Device.is_valid_name("主轴电机"))  # True
```

**多态效果**：同一个 `d.start()`，`Motor` 调用的是重写后的版本，其他设备调用父类版本——这就是继承 + 多态的威力。

## 八、常见坑

- **忘了 `super().__init__()`** → 父类属性（name/status）没初始化，AttributeError
- **@property 方法名和存值的属性名冲突**：存值用 `_run_hours`，暴露用 `run_hours`，别同名
- 重写方法后想用父类逻辑 → `super().start()`，不要复制粘贴父类代码
- `isinstance` 和 `type(obj) == Device` 的区别：isinstance 包含子类，type 只认精确类型
