## 一、地基：函数是一等公民

Python 的函数可以像变量一样：赋值、当参数传、当返回值返回。

```python
def greet(name):
    return f"你好 {name}"

f = greet          # 函数赋值给变量（不调用，不带括号）
print(f("小明"))    # 你好 小明
```

**C++ 类比**：函数指针 / `std::function` / lambda。Python 里一切皆对象，函数也是对象。

## 二、闭包（类比 C++ lambda 捕获）

内部函数 + 捕获的外部变量 = 闭包。类比 C++ lambda 的 `[&]` / `[=]` 捕获。

```python
def make_counter():
    count = 0                 # 外部变量（被捕获）
    def counter():            # 内部函数
        nonlocal count        # 关键：声明"我要修改外部变量"（不写会报错或只读）
        count += 1
        return count
    return counter            # 返回函数——它带着 count 的"记忆"

c = make_counter()
print(c())   # 1
print(c())   # 2   ← count 被记住了！这就是闭包
```

要点：`nonlocal` 声明修改外部变量（C++ lambda 里 `[&count]` 的效果）。

## 三、装饰器（你天天写 @，今天揭开它）

**装饰器 = 接收函数、返回新函数的函数**。`@timer` 只是语法糖，等价于：

```python
def timer(func):                    # 接收一个函数
    def wrapper(*args, **kwargs):   # 新函数：包一层逻辑
        start = time.time()
        result = func(*args, **kwargs)   # 调用原函数
        print(f"{func.__name__} 耗时 {time.time() - start:.2f}s")
        return result
    return wrapper                  # 返回新函数

@timer                             # 等价于 slow_thing = timer(slow_thing)
def slow_thing():
    time.sleep(1)
    return "done"
```

**`*args/**kwargs` 终于派上用场了**（第 1 课自测考过）：wrapper 要能接住原函数的任意参数，原样转交。

**你已经用过的装饰器**：
- `@property` / `@classmethod` / `@staticmethod`——Python 内置装饰器
- `@app.post("/chat")`——FastAPI 的装饰器，背后就是"接收函数 → 注册路由 → 返回包装函数"

**装饰器常用场景**：计时、日志、权限校验、缓存——不改原函数代码，给函数"加装备"。

## 四、生成器（yield = 暂停，你早已在用）

`yield` 的魔法：**函数执行到 yield 暂停，把值交出去；下次调用从暂停处继续**。

```python
def countdown(n):
    while n > 0:
        yield n          # 暂停 + 交值
        n -= 1           # 下次从这里继续

for i in countdown(3):
    print(i)             # 3 2 1
```

**你已经在用生成器了**：
- `resp.iter_lines()`（chat2 流式）——逐行产出的迭代器
- `client.chat(..., stream=True)`（chat5 流式）——SDK 返回生成器，逐块产出
- FastAPI `StreamingResponse(生成器)`——边生成边发给客户端

生成器 vs 普通函数：**不一次性算完**，用多少算多少——省内存（类比 C++ 惰性求值/迭代器）。

生成器表达式（和推导式只差括号）：`(x * x for x in range(10))`

## 五、迭代器（for 循环的秘密）

- **可迭代对象**（iterable）：`list` / `dict` / `str` / 生成器……能 `for x in ...` 的都是
- for 循环内部：`iter(obj)` 拿到迭代器 → 反复 `next()` 直到 `StopIteration`
- **生成器就是迭代器**（一种特殊的迭代器）

```python
lst = [10, 20, 30]
it = iter(lst)          # 拿迭代器
print(next(it))         # 10
print(next(it))         # 20
```

## 六、正则（re 模块，你已用过 re.sub 过滤 think 标签）

```python
import re

text = "设备E-102报警，温度85.5℃，压力2.3MPa"

nums = re.findall(r"\d+\.?\d*", text)   # 提取所有数字
print(nums)                              # ['102', '85.5', '2.3']

match = re.search(r"E-\d+", text)        # 查找第一个匹配
print(match.group())                     # E-102

clean = re.sub(r"报警", "告警", text)     # 替换
```

**常用模式速查**：

| 模式 | 含义 | 例子 |
|---|---|---|
| `\d` | 数字 | `\d+` 一个或多个数字 |
| `\w` | 字母/数字/下划线 | `\w+` 单词 |
| `.` | 任意字符（除换行） | `.*` 任意长度 |
| `*` `+` `?` | 0次/1次以上/0或1次 | `\d+` |
| `^` `$` | 开头 / 结尾 | `^\d+$` 纯数字 |
| `[...]` | 字符类 | `[a-zA-Z]` 字母 |
| `.*?` | 非贪婪（尽量短） | 过滤 think 标签用过 |

**非贪婪 `.*?` 很重要**：`<think>.*?</think>` 匹配最短内容，能正确配对标签。

## 八、常见坑

- 闭包里修改外部变量忘写 `nonlocal` → `UnboundLocalError`
- 装饰器忘返回 `wrapper` → 原函数变 None，调用报错
- `re.findall` 和 `re.search` 别混：findall 返回全部列表，search 返回第一个匹配对象（要 `.group()`）
- 生成器只能遍历**一次**，第二次遍历是空的（不是 bug，是设计）
