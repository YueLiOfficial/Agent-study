## 二、C++ → Python OOP 对照速查（核心差异）

| C++ | Python | 关键差异 |
|---|---|---|
| `class Foo { Foo(...); }` | `class Foo:` + `def __init__(self, ...)` | 构造用 `__init__`，必须带 `self` |
| `this->x` | `self.x` | `self` 就是 `this`，但**每个方法都要显式写** |
| `private: / protected:` | `_x`（下划线约定） | **没有真正的访问控制**，全靠自觉 |
| `getX()/setX()` | `@property` / `@x.setter` | 属性装饰器，更优雅 |
| `virtual` 多态 | 方法重写（无需声明） | Python 天生多态，不用 virtual |
| `~Foo()` 析构 | 基本不写 | 垃圾回收（GC）自动管内存 |
| 运算符重载 `operator==` | 魔法方法 `__eq__` | 见下节 |

**最重要的一个差异：`self` 必须作为每个方法的第一个参数显式写出**——新手 99% 的错误是忘了写 self。

## 三、第一个类：Device（工业设备，你的主场）

```python
class Device:
    """工业设备类（docstring：类的说明文档）"""

    def __init__(self, name, status="待机"):
        """构造方法：创建对象时自动调用（类比 C++ 构造函数）"""
        self.name = name          # 实例属性（类比 this->name）
        self.status = status
        self.run_hours = 0        # 累计运行小时

    def start(self):
        """成员方法：第一个参数必须是 self"""
        if self.status == "运行中":
            print(f"{self.name} 已经在运行了")
            return
        self.status = "运行中"
        self.run_hours += 0       # 占位，后面练习加计时
        print(f"{self.name} 启动")

    def stop(self):
        self.status = "待机"
        print(f"{self.name} 停止")

    def __str__(self):
        """魔法方法：print(对象) 时自动调用（类比 operator<< 输出）"""
        return f"设备[{self.name}] 状态={self.status} 运行{self.run_hours}小时"


# ===== 使用 =====
pump = Device("冷却水泵")        # 自动调用 __init__（类比栈上构造）
pump.start()                     # 输出：冷却水泵 启动
print(pump)                      # 触发 __str__：设备[冷却水泵] 状态=运行中 运行0小时

pump2 = Device("空压机", "故障") # 构造时传初始状态
print(pump2)
```

## 四、魔法方法（Python 的"运算符重载"）

`__xxx__` 双下划线方法 = 魔法方法，Python 在特定场景自动调用：

| 魔法方法 | 触发时机 | C++ 类比 |
|---|---|---|
| `__init__` | 创建对象 | 构造函数 |
| `__str__` | `print(obj)` / `str(obj)` | `operator<<` |
| `__repr__` | 调试显示（repr(obj)） | `toString()` 调试版 |
| `__len__` | `len(obj)` | `size()` |
| `__eq__` | `obj1 == obj2` | `operator==` |
| `__lt__` | `obj1 < obj2`（排序用） | `operator<` |
| `__getitem__` | `obj[key]` | `operator[]` |

**够用原则**：现阶段重点掌握 `__init__` 和 `__str__`，其他遇到再学。

## 六、常见坑

- **忘写 self** → `TypeError: start() takes 1 positional argument but 2 were given`（经典报错，见到别慌）
- 属性没在 `__init__` 里定义，却在别的方法里用 → `AttributeError`，尽量把所有属性初始化在 `__init__`
- `__str__` 必须 `return` 字符串，不能 `print`（否则 TypeError）
- 类里缩进统一 4 空格，方法之间空一行
