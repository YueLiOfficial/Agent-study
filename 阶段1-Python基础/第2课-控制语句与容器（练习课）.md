## 一、C++ → Python 对照速查

| C++ | Python | 说明 |
|---|---|---|
| `for (int i=0; i<n; i++)` | `for i in range(n):` | range 左闭右开 |
| `for (auto x : v)` | `for x in lst:` | 直接遍历 |
| `while (x)` | `while x:` | 别忘了冒号 |
| `switch (n)` | `if/elif/else`（3.10+ 也可 `match`） | Python 无 switch |
| `std::vector<int> v` | `v = [1, 2, 3]` | 列表可变 |
| `std::map<K,V> m` | `d = {"k": "v"}` | 字典 |
| `std::string s` | `s = "abc"` | 字符串不可变，返回新串 |
| 索引 `s[i]` | `s[1:4]` 切片 / `s[::-1]` 反转 | 切片是 Python 核心武器 |
| `std::find(...)` | `x in lst` / `x in d`（字典 O(1)） | `in` 运算符 |
| 遍历 map | `for k, v in d.items():` | 解包遍历 |

## 二、LLM 开发必会的 8 个容器技巧（速览即可，练习里会用到）

```python
lst = ["a", "b", "c"]
# 1. enumerate：同时拿下标和值
for i, v in enumerate(lst):
    print(i, v)                     # 0 a / 1 b / 2 c

# 2. zip：并行遍历两个列表
names = ["Tom", "Jerry"]
ages  = [30, 25]
for n, a in zip(names, ages):
    print(n, a)

# 3. 切片：s[start:end:step]
s = "abcdef"
print(s[1:4])   # bcd（含头不含尾）
print(s[::-1])  # fedcba（反转）

# 4. 列表推导式（带过滤）
squares = [x**2 for x in range(20) if x % 2 == 0]

# 5. 字典推导式
names = ["a", "b", "c"]
d = {name: i for i, name in enumerate(names)}   # {"a": 0, "b": 1, "c": 2}

# 6. join：列表 → 字符串
print(", ".join(["a", "b", "c"]))   # a, b, c

# 7. sorted 排序（不改变原列表）
nums = [3, 1, 2]
print(sorted(nums))                 # [1, 2, 3]
print(sorted(nums, reverse=True))   # [3, 2, 1]

# 8. set 去重
unique = set([1, 2, 2, 3, 3, 3])    # {1, 2, 3}
```

## 五、常见坑

- `range(1, i+1)` 写错边界 → 乘法表多一行/少一行
- 猜数字里 `input()` 返回的是**字符串**，比较前要 `int()` 转换
- 直接 `print(lst)` 嵌套列表显示 `[[...], [...]]` 很正常，别慌
- `random.choice(offices)` 是等概率随机选一个办公室；`random.shuffle(names)` 是原地打乱列表
